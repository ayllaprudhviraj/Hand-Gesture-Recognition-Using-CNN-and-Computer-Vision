# Kaggle ASL Alphabet Dataset

- Dataset: [ASL Alphabet Dataset](https://www.kaggle.com/datasets/dorukdemirci/asl-alphabet-dataset)
- Publisher: Doruk Demirci
- Kaggle reference: `dorukdemirci/asl-alphabet-dataset`, version 1
- License reported by Kaggle: Apache License 2.0
- Contents: 2,427 labeled hand images for A-Y, excluding motion-based J and Z

The project uses the existing local dataset for blank, J, and Z classes. The Apache License 2.0 text is included alongside these files.
